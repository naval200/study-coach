Commands

Type /study-coach and a command. You can also ask in normal words.

CommandUse it when
todayYou want to know what to do now
logYou finish a block or a day
statusYou want to know your progress
check <concept>You want to test what you know
adapt <change>You want to change the plan
shareYou want to write a post
capture <item>You want to save an idea, article, or book
reviewThe week ends (usually Sunday)
init <file>You start a new plan

If you give no command, the coach uses today.

today

  1. If reviews are due, the coach offers a 5–10 minute review first.
  2. It shows the tasks for today, with times. The list fits on one screen.
  3. It tells you where owed items go. It does not add them to today, unless today is the catch-up day.
  4. If today has a Post item, it suggests a topic.
  5. It ends with one action to do now.

log

  1. Tell the coach what you did and how many hours.
  2. The coach ticks only the items that you confirm.
  3. It writes the Done, Blocked, and Tomorrow lines.
  4. If an item says "explain" or "from memory", the coach asks a quick question first.
  5. It updates course and book progress. Then it tells you your pace.

status

The coach gives 8 lines or less. Then it gives one recommendation:

  • Ahead: it names the win. It suggests more depth, not future work.
  • Behind: it gives the numbers. It suggests a scope cut that keeps the deliverable for this week.
  • On track: one line, and the next step.

capture

  • idea: The coach adds one line to ideas/inbox.md.
  • article: The coach makes a notes file. Then it asks 2–3 questions about the article.
  • book: The coach makes or updates the book file and ticks chapters.

review

  1. The coach writes reviews/week-N.md: numbers, what worked, what did not, one change.
  2. It decides on waiting proposals and sorts the idea inbox.
  3. It clears the catch-up list.
  4. It runs the due concept reviews.
  5. It offers to write a weekly post.

init

  1. The coach saves your plan as curriculum/plan.md.
  2. It asks for the start date, hours, goal, and other settings.
  3. It writes STUDY.md.
  4. It makes one day file for each day, and all other files.
  5. It shows the today view.
