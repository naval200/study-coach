Put your progress online

A free web page that shows your plan and your progress. The coach updates it after each log. You do not need to know git.

Type this in Claude Code, in your study folder:

/study-coach online

The coach does the work one step at a time. It explains each step. It stops when it needs you.

What you get

  • A page at an address like https://yourname.github.io/study/. You can send this link to friends, a mentor or an employer.
  • An online copy of all your study files. If your computer breaks, your plan and logs are safe.
  • Automatic updates. After each log, check or review, the coach saves your files and sends them online. The page changes in about 1 minute.

This is optional. Without it, the coach works the same way. Your files stay only on your computer.

The words, in plain English

WordMeaning
gitA free program that saves versions of a folder. One saved version is a commit.
GitHubA website that keeps an online copy of a git folder. It is free for this use.
Repository (repo)The online copy of one folder on GitHub.
PushSend your new commits to GitHub.
GitHub PagesFree web hosting from GitHub. It shows the index.html file from your repo as a web page.
ghThe GitHub program for the terminal. The coach uses it to make the repo and turn on Pages.

What you do, and what the coach does

StepYouThe coach
1. ChooseChoose: online page, backup only, or local only.Explains the choices.
2. ToolsRun the install command if the coach asks. It can need your computer password.Checks for git and gh. Gives the install command for your computer.
3. AccountMake a free account at github.com/signup. Verify your email.Tells you what to choose on each screen.
4. Sign inType ! gh auth login and follow the browser steps.Tells you which options to pick. Checks that the sign-in works.
5. RepoSay yes to the name, and to public or private.Makes the repo, adds the page, and saves the settings.
6. First saveRead the file list. Say yes.Shows the files that go online. Then sends them.
7. PageOpen the link.Turns on GitHub Pages and waits until the page is ready.
The coach never makes accounts for you. It never types or reads your password. You do the sign-in in your own browser.

Public or private?

  • Public: anyone can read your study files. A free account needs a public repo for the web page. This is good if you learn in public.
  • Private: only you can see the files. A free account gets no web page, but you get an online backup.

Put personal notes in private.md. The coach adds it to .gitignore, a list of files that git does not save. The save script also refuses private.md and .env files.

Your code in projects/ does not go online automatically. Tell the coach if you want it to.

After setup

You do nothing more. At the end of each log, the coach writes one line, for example:

sync: saved 6 file(s) (commit 7855e05), pushed to origin/main.
sync: online dashboard: https://yourname.github.io/study/ (updates in about 1 minute).

The page has checkboxes. Ticks on the page stay in your browser only. To record them, click Copy for coach. Then paste the text into /study-coach log.

Settings

The settings are at the top of STUDY.md:

sync: auto          # auto = save and send after each change
                    # ask  = ask you each time
                    # off  = do not save online
remote: origin
pages_url: https://yourname.github.io/study/

To stop the automatic save, change sync: auto to sync: off.

Problems

"GitHub did not accept your login"

Your sign-in ended. Type ! gh auth login again, then ! gh auth setup-git. Then ask the coach to save again.

"no network"

Nothing is lost. The coach saved a commit on your computer. It sends it the next time you log with a network.

The page shows "404"

The first page can take up to 10 minutes. Wait, then reload. If it still shows 404, ask the coach: "check my GitHub Pages".

"the online copy has changes that conflict"

You changed a file on GitHub and on your computer. Ask the coach to fix it. It keeps both changes.

I already have a repo for my study folder

Run /study-coach online. The coach finds the repo and only adds the missing parts.
