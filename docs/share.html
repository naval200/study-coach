Posts

Write one time. Change it for each platform. You do not need video.

The main rule

Each post must give a reader something useful: a number, an error to avoid, a how-to, or a comparison. A diary entry is not sufficient.

The coach uses only your real logs and numbers. If a number is missing, it asks you. It does not invent results.

Steps

  1. The coach suggests 2–3 topics. You select one.
  2. It writes a draft in posts/DATE-NAME/blog.md. It marks missing parts with TODO(you).
  3. It writes short versions in variants.md.
  4. It checks the draft: no secrets, correct numbers, working links.
  5. After you publish, it adds a line to posts/published.md and ticks the Post item.

Short versions

PlatformSize
LinkedIn150–250 words, one real number
X / Threads5–8 posts, 280 characters or less each
Instagram carousel6–8 slides, 25 words or less each, plus caption
YouTube communityShort text and an image
Voice-over (optional)60 seconds, to read over the slides

Set your platforms with post_formats in STUDY.md.

How often

Follow the Post items in your plan. If you have little time, write only one short post each day. Write the long blog and a carousel at the weekly review.

One good post is better than three weak posts.
