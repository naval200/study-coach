Your study folder

All data is in plain markdown files. You can read and edit them.

How the coach finds the folder

The coach looks for a file named STUDY.md. It looks in this order:

  1. The current folder.
  2. The study/ folder.
  3. Each parent folder.

If it does not find the file, it offers to make a new folder with init.

A day file

Each day file has four parts:

## Plan
- [ ] **Learn:** ...
- [ ] **Build:** ...
- [ ] **Post:** ...

## Done when
- [ ] A result that you can see or measure

## Log
- **Done:**
- **Blocked:**
- **Tomorrow's first task:**

## Notes

Use these marks in the boxes:

  • [ ] = not done
  • [x] = done
  • [-] = dropped (write the reason in Notes)

Items with (stretch) or (if behind) are optional. They do not count as owed work.

The dashboard

A script reads all the files and writes DASHBOARD.md. The coach runs this script first, each time. It shows:

  • Day N of M, and your pace
  • Items that you owe
  • Your streak and missed days
  • Concepts that are due for review
  • Errors that occur again and again
  • Plan changes and posts
The coach uses the numbers from the script. It does not count by hand.
